# Project Description

## Introduction
The project is an AI Based Smart Car Parking System using ESP32-CAM. It is intended to make parking easier and more efficient by monitoring parking-space availability and capturing vehicle images/number plates.

## Problem Statement
Finding parking spaces can be difficult. Manual parking management can waste time and fuel, while drivers may not have real-time information about available spaces.

## Objectives
- Detect vehicles in the parking area.
- Monitor parking spaces in real time.
- Mark spaces as occupied or free.
- Capture vehicle number plates/images using ESP32-CAM.
- Reduce manual intervention.

## Components
- ESP32-CAM
- Servo Motor
- IR Sensor Module
- LCD Display
- Breadboard
- Jumper Wires
